# Gleanx 软件介绍与使用说明
适用系统：Windows 10 / Windows 11  
下载入口：https://github.com/dcxa521gi/Gleanx/releases/latest

## 1. 软件定位

Gleanx 是一款 Windows 本地效率工具，核心目标是：**让每一次复制都有迹可循，让每天的使用轨迹都能被整理、复用和回看。**

它不只是剪贴板工具，还集成了：

- 剪贴板历史管理
- 图片 / 视频 / 音频 / 文件记录
- 右键菜单管理
- 开机启动项管理
- 定时启动任务
- 桌面整理
- AI 心迹生成
- 心迹海报生成
- AI 壁纸生成
- 节日弹窗与节日海报
- AI 生成图库管理
- 多通道通知推送
- 数据备份、导入、清理与占用统计
- GitHub Releases 自动更新
- 官网入口：https://gleanx.vo56.com

## 2. 主要功能

### 2.1 剪贴板管理

Gleanx 会自动记录复制过的内容，包括：

- 文本
- 图片
- 视频文件
- 音频文件
- 普通文件
- 其他长内容

支持能力：

- 搜索历史记录
- 按类型筛选
- 按日期筛选
- 点击记录再次复制
- 置顶常用记录
- 删除与回收站恢复
- 内容快捷键
- 本地文件显示文件图标、文件名、后缀和原始路径
- 图片缓存固定保存到数据目录
- 复制图片后可通过已配置 AI 自动 OCR 识别内容并整理标题

### 2.2 右键菜单管理

用于管理 Windows 右键菜单项，可启用、禁用或删除相关菜单项。

### 2.3 开机启动管理

用于查看和管理系统开机启动项，包括：

- Windows 启动文件夹项目
- 注册表启动项
- 自定义启动项
- 禁用列表与恢复

### 2.4 定时启动任务

可配置定时启动应用、文件、文件夹或网址。任务自动执行后，会向已配置的通知渠道推送“某某任务已启动”的提示。

### 2.5 桌面整理

可分析桌面文件，并按类型进行整理。

支持：

- 全部整理
- 单分类整理
- 分类图标显示
- 恢复整理前状态

### 2.6 AI 心迹

心迹会根据剪贴板文本记录生成一段每日总结，帮助用户回看当天或昨日的工作状态、情绪和重点。

支持：

- 今日 / 昨日心迹
- 自动生成时间
- 回复风格设置
- 心迹海报生成
- 多张海报累加管理
- 心迹内容自动推送到已配置通知通道

### 2.7 AI 心迹海报

心迹可生成海报，支持多种风格与尺寸。

当前支持风格包括：

- 温暖卡片
- 报纸
- 电影海报
- 极简
- 手帐
- 赛博霓虹
- 水彩插画
- 复古胶片
- 暗黑高级
- 国风宣纸

### 2.8 AI 壁纸

支持通过星境 AI 生图接口生成桌面壁纸。

支持：

- 1–6 张生成数量
- 2K / 4K 质量
- 自动累加到壁纸来源
- 定时切换壁纸
- 随机 / 顺序 / 单张模式

### 2.9 节日弹窗

可在设置中启用节日弹窗。

支持：

- 仅提醒中国公历节日、农历节日与二十四节气
- 节日前 7 天、5 天、3 天、1 天和当天提醒
- 自动 30 秒关闭或手动关闭
- 节日信息展示
- 距离节日时间展示
- AI 生成节日用心文案
- 手动或自动生成节日海报
- 节日海报默认 9:16
- 图片一键复制
- 不叠加弹窗
- 多天未打开时仅弹出最新一天需要提醒的节日信息

### 2.10 图库管理

图库管理集中展示软件中 AI 生成的图片，包括：

- AI 壁纸
- 心迹海报
- 节日海报

支持：

- 打开图片目录
- 缩略图查看
- 点击放大
- 查看原图
- 右键重新生成
- 右键跳转到图片目录

### 2.11 通知推送

支持以下通知通道：

- Meow
- 飞书
- 钉钉
- Bark
- WPUSH

可用于：

- 复制内容自动推送
- 心迹生成结果自动推送

心迹推送中的图片链接使用 AI 生图结果链接，便于在通知渠道中点击查看。

### 2.12 数据管理

支持：

- 导出备份
- 导入备份
- 清空非置顶数据
- 统计数据占用

数据占用统计包含文本、图片、视频、文件、AI 壁纸、心迹、海报等实际数据目录内容。

### 2.13 自动更新

Gleanx 使用 GitHub Releases 作为分发和自动更新来源。

支持：

- 设置页检查更新
- 左上角版本号更新提示
- 下载进度显示
- 下载完成后重启安装

## 3. 基础使用流程

### 3.1 安装

1. 打开 GitHub Releases：  
   https://github.com/dcxa521gi/Gleanx/releases/latest
2. 下载最新版 `Gleanx-Setup-x.x.x.exe`。
3. 双击安装。
4. 启动 Gleanx。

### 3.2 配置 AI 接口

进入：`设置 → AI 接口`

填写：

- API URL
- API Key
- Model

用于心迹文案、节日文案等文本生成。

### 3.3 配置星境 AI 生图

进入：`设置 → 星境 AI 生图`

填写：

- 生图 API URL
- API Key
- 图片模型
- 默认尺寸

用于 AI 壁纸、心迹海报、节日海报。

### 3.4 配置通知通道

进入：`通知`

选择通道并填写对应配置。

建议至少配置一个通道，用于接收复制内容或心迹结果。

### 3.5 使用心迹

进入：`心迹`

1. 配置生成范围、时间、回复风格、海报风格。
2. 点击生成今日或昨日心迹。
3. 需要海报时点击生成海报。
4. 已启用通知通道时，心迹结果会自动推送。

### 3.6 使用图库管理

进入：`图库管理`

可查看软件中所有 AI 生成图片，并进行放大、查看原图、跳转目录或重新生成。

## 4. 数据目录说明

Gleanx 数据目录默认位于安装目录下的 `Data` 文件夹；如果安装目录不可写，程序会自动切换到可写的数据目录。

常见子目录：

- `clipboard-images/`：剪贴板图片缓存
- `clipboard-files/`：剪贴板本地文件、视频和音频缓存
- `heartprints/`：心迹 JSON 记录
- `heartprint-posters/`：心迹海报
- `ai-wallpapers/`：AI 壁纸
- `festival-posters/`：节日海报

## 5. 更新维护格式

每次发布新版本时，应同步更新本文档中的：

- 当前版本号
- 新增功能
- 调整后的使用方式
- 通知通道变化
- 数据目录变化
- 自动更新或发布方式变化

同时需要同步更新：

- `website/index.html`
- `docs/releases/vX.X.X.md`
- GitHub Release 文案

## 7. v1.0.14 使用变化

- 软件右上角官网入口已改为：https://gleanx.vo56.com。
- 设置中的全局文字颜色只在明亮模式下按用户设置生效；暗色模式自动使用白色或浅色文字，避免不可读。
- 全局文字颜色调节框右侧新增“恢复默认”按钮。
- 心迹生成改为主进程持续任务，切换到其他功能页后不会中断，返回心迹页仍可看到生成状态或结果。
- 剪贴板媒体缩略图加载和前端事件监听做了性能优化，减少卡顿。

## 8. v1.0.15 使用变化

- 剪贴板支持捕获本地复制的图片、视频、音频和其他文件。
- 剪贴板新增“音频”分类；“文件”分类包含压缩包、txt、pdf、word、xls、xlsx 等所有除图片、视频、音频之外的文件。
- 数据管理页新增“附件等数据存储路径”，可点击“更换目录”迁移所有数据。
- 更换数据目录后，新的复制文件类数据会保存到新目录中。
- 定时壁纸设置现在会显示设置成功或失败提示。
- 节日弹窗节日库扩充为中国传统/现代节日及常见国际节日。（v1.0.16 起已按用户反馈收敛为中国公历节日、农历节日与二十四节气。）
- 设置页节日弹窗新增“测试弹窗”，可选择节日测试文案和节日海报。
- 设置页节日弹窗新增历史记录，可查看历史弹窗文本和海报。

## 9. v1.0.16 使用变化

- 深度修复 v1.0.15 剪贴板文件检测导致的主进程卡顿：文件列表读取改为异步、节流、避免并发阻塞。
- 节日弹窗移除国外节日，只保留中国公历节日、农历节日和二十四节气。
- 节日海报手动生成失败时会在弹窗中显示错误提示，不再静默无反应。
- 数据页“附件等数据存储路径”的路径框与“更换目录”按钮已对齐。
- 复制本地文件时，剪贴板列表显示文件图标、文件名称、后缀和原始路径。
- 剪贴板顶部“内容快捷键”和“回收站”改为图标按钮，数量显示为右上角数字角标。
- 复制图片后，如已配置 AI 文本模型，会自动识别图片内容并整理标题；开启剪贴板通知时，图片推送内容为“标题 + [图片]”。
- 定时壁纸自动更换成功后会推送通知；定时启动任务自动执行后会推送任务启动通知。
